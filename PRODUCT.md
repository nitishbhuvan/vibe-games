# Product

## Register

product

## Users
Casual web gamers, mobile phone gamers, retro arcade lovers, and Python web enthusiasts looking for instant, coffee-themed, zero-install browser games on both mobile devices and desktop.

## Product Purpose
Vibe Games is a coffee-themed browser game hub featuring instant playable arcade, 2-player local duels, puzzle solvers, drift racing, incremental clickers, and Python web games. It provides fluid touch-responsive gameplay on smartphones, auto-saves high scores and playtime locally, and delivers a cozy coffee aesthetic.

## Brand Personality
Warm, Cozy, Arcade-Crafted (Espresso Roast & Creamy Vibes)

## Anti-references
Cluttered ad-heavy web game portals (e.g., generic Flash clones with unreadable text, broken fixed-width desktop canvases, and missing mobile controls).

## Design Principles
- Mobile-First Touch Fluency: Every single game must be seamlessly playable on smartphones with responsive scaling and dedicated virtual touch controls or gestures.
- Warm Coffee Aesthetics: Rich espresso dark and light cream palettes with tactile feedback, micro-animations, and crisp readable typography.
- Zero Friction: Instant play, responsive canvases fitting small screens, safe area insets, and persistent local storage tracking.

## Accessibility & Inclusion
Touch targets ≥44x44px, safe area padding for modern notched phones, high text contrast ratios (≥4.5:1), fully adaptive layouts from 320px to large screens.
